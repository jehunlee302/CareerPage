## ux-05 · 요소별 화면 개선
이유: 2026-11-12 화면 재구성 검토에서 섹션 순서는 유지하고 요소만 고치기로 결정 (개선안 E + 사용자 피드백).
- Hero: 언어에 맞는 이력서 버튼 1개, 태그 줄 삭제, 휴대폰 사진 축소.
- 주요 수치는 해당 섹션으로 가는 링크.
- 접기(철학 본문 "더 읽기", 학위 논문 상세, 경력 상세)는 모두 `<details>`, 문구는 화면 언어를 따름.
- 학력은 학사부터. 병역은 작은 배지.
- 주요 프로젝트와 전체 프로젝트는 같은 카드(`projectCard`). 카드 위에 기간과 참여 기간("5m (5y)" → "5개월 (전체 5년)"). 제목이 60자를 넘으면 글자를 줄임. 주요 프로젝트 카드에만 성과 한 줄.
- 프로젝트(4×2)·논문(2×3)·수상(2×3)·활동(2×3)은 페이지 단위 가로 넘기기(화살표·스와이프). 목록 위 오른쪽과 아래 오른쪽에 같은 넘기기(← 1 / 4 →). 화면 폭이 좁으면 열 수를 2·1로 줄임. 논문 번호 숨김.
- 기술은 4열 고정 배치(`skills.yaml`의 `column`): AI·학습 방법론 / 개발 환경·프로그래밍 언어 / 최적화·언어 / 라이브러리·시뮬레이션. 특허는 기존 섹션 유지.
- 연구 분야에 AI 에이전트 시스템(AI-ready 데이터·LLM 위키·온톨로지)·AI 에이전트 서비스(백엔드·운영 안정성·배포) 추가 (4열).
- 휴대폰 첫 화면 버튼(연락·이력서·LinkedIn·Scholar)은 작게 2×2.
- 한국어 화면은 단어 단위 줄바꿈.
- 카드·항목 안쪽 여백을 줄여 한 화면에 더 보이게 함.
- QA: 영어·한국어, 휴대폰(390px)·데스크톱, 밝은·어두운 테마에서 가로 스크롤 없음, 콘솔 오류 없음.
