## ux-05 · 요소별 화면 개선
이유: 2026-11-12 화면 재구성 검토에서 섹션 순서는 유지하고 요소만 고치기로 결정 (개선안 E + 사용자 피드백).
- Hero: 언어에 맞는 이력서 버튼 1개, 태그 줄 삭제, 휴대폰 사진 축소.
- 주요 수치는 해당 섹션으로 가는 링크.
- 상세(철학 본문, 학위 논문, 경력, 프로젝트)는 모두 같은 팝업. 카드 오른쪽 위에 상자 없는 글자 "Details ↗"/"상세 ↗", 카드를 눌러도 열림. 키보드로 열고 Esc로 닫으면 포커스가 버튼으로 돌아옴.
- 학력 카드에는 논문 제목 대신 상세 팝업, 지도교수 홈페이지는 🔗 아이콘. 학력·경력 카드 오른쪽 위는 기간과 "상세 ↗" 한 줄, 근무지는 기관명 옆(빈 여백 제거).
- 같은 회사·같은 직함이 이어지는 경력은 카드 하나로 묶음(지금은 VMS 솔루션스 두 건). 기간과 전문연구요원 기간은 처음 시작~마지막 끝 한 줄, 팝업에 부서별로 기간·역할·수행 내용. 이력서(PDF)는 그대로 두 건.
- 프로젝트·수상·활동 카드는 같은 줄의 카드끼리 항목 높이를 맞춤(CSS subgrid). 값이 없는 항목도 자리를 비워 두어 아래 항목 위치가 같음.
- 전체 프로젝트 필터는 "PM"과 "PL" 따로(PL 프로젝트가 하나도 없으면 PL 버튼은 숨김).
- 활동 카드 아이콘은 하나씩: 조교 🎓, 멘토 💬, 연구실 대표 🔬, 농구 동아리 🏀, 그 밖의 학생회 🏫. 가장 작은 글자는 0.7rem 이상.
- 학력은 학사부터. 병역은 작은 배지.
- 주요 프로젝트와 전체 프로젝트는 같은 카드(`projectCard`). 카드 위에 기간과 참여 기간("5m (5y)" → "5개월 (전체 5년)"). 제목 글자 크기는 하나로 통일. 성과·수행 내용은 카드에 쓰지 않고 상세 팝업에만. 태그는 한 줄, 넘치면 긴 태그부터 말줄임(…). 학력·경력 카드의 "Details ↗"는 화면 폭과 상관없이 카드 오른쪽 위. 소속기관·협력사·고객사는 이름표를 붙여 보통 굵기로 표시(어두운 배경에서도 읽히는 색).
- 프로젝트(3×2, 태그는 한 줄이고 넘치면 오른쪽 끝이 흐려짐; 필터에 쓰는 태그가 앞)·논문(2×3)·수상(3×2)·활동(3×2)은 페이지 단위 가로 넘기기(화살표·스와이프). 목록 위 오른쪽과 아래 오른쪽에 같은 넘기기(← 1 / 4 →). 화면 폭이 880px 미만이면 2열, 600px 미만이면 1열(논문은 1024px 미만이면 1열). 넘기기 목록 안 카드는 나타날 때 위로 미끄러지지 않음(아래쪽 잘림 방지). 논문 링크는 상자 없는 글자로 카드 오른쪽 위.
- 기술은 4열 고정 배치(`skills.yaml`의 `column`): AI·학습 방법론 / 개발 환경·프로그래밍 언어 / 최적화·언어 / 라이브러리·시뮬레이션. 특허는 기존 섹션 유지.
- 연구 분야는 이모티콘 없이 제목·설명만. AI 에이전트 시스템(AI-ready 데이터·LLM 위키·온톨로지)·AI 에이전트 서비스(백엔드·운영 안정성·배포) 추가 (4열).
- 휴대폰 첫 화면 버튼(연락·이력서·LinkedIn·Scholar)은 작게 2×2.
- 한국어 화면은 단어 단위 줄바꿈.
- 카드·항목 안쪽 여백을 줄여 한 화면에 더 보이게 함.
- QA: 영어·한국어, 휴대폰(390px)·데스크톱, 밝은·어두운 테마에서 가로 스크롤 없음, 콘솔 오류 없음.

<a id="ux-06"></a>
## ux-06 · 에디토리얼 화면 구성
이유: 2026-11-21 화면 구성 대안 검토(레퍼런스 `references/ui-refs/homepage/good` 73장 → 시안 A·B·C)에서 추천안(A 에디토리얼 인덱스 + C의 경력 화면)으로 진행. 목록이 길어(프로젝트 27·논문 약 50) 페이지 넘기기로는 전체가 한눈에 안 보이는 문제를 푼다.
- 바뀌는 것은 배치와 모양뿐. 지금 화면에 나오는 항목은 하나도 빼지 않는다(아래 섹션별로 자리를 정함). 데이터 흐름(YAML → JSON), 섹션 순서, 영어·한국어 전환, 밝은·어두운 테마, 휴대폰 햄버거 메뉴, `esc()`·`safeUrl()`, 외부 라이브러리 없음도 그대로.
- 바탕: 밝은 종이색 배경, 큰 글자, 얇은 선으로 구분. 카드 상자와 그림자는 쓰지 않음. 남색 첫 화면과 어두운 섹션 띠(Featured·Contact)는 없앰. 어두운 테마는 거의 검정 배경에 같은 배치. 회색 글자는 배경과 명암비 4.5:1 이상.
- 섹션 머리: 왼쪽에 섹션 이름(스크롤해도 따라옴), 오른쪽에 내용. 880px 미만은 위아래로 쌓음.
- 첫 화면: 이름을 아주 크게, 아래 줄에 돌아가는 직함(타이핑 효과 유지). 오른쪽 좁은 칸에 작은 사진·한글 이름·요약. 버튼은 지금과 같음(연락·이력서·LinkedIn·Scholar). 아래 줄에 주요 수치 5개(누르면 해당 섹션).
- 철학: 큰 글자 한 문단(첫 문장 진하게, 나머지 회색) + 기둥(pillars) 3개는 선으로 나눈 3열. 본문은 지금처럼 상세 팝업.
- 연구 분야·기술: 선으로 나눈 열 목록(연구 3열, 기술은 지금 4열 배치 그대로), 연구에는 "01" 같은 작은 번호.
- 학력: 한 줄씩(학위·전공 / 학교·지도교수 🔗 / 기간). 논문이 있으면 줄 안의 "Details ↗" 버튼으로 팝업.
- 경력: 왼쪽에 경력 목록(지금처럼 같은 회사·같은 직함은 하나로 묶음), 오른쪽에 고른 항목의 상세(직함·회사·부서·근무지·기간·역할·수행 내용·성과·전문연구요원 기간, 묶인 경력은 부서별 소제목). 경력 팝업은 없앰. 목록은 탭(`role=tablist`·`aria-selected`), 휴대폰에서는 위쪽 가로 탭.
- 주요 프로젝트: 3열, 위에 굵은 선, 큰 제목, 아래에 번호·기간·참여 기간·소속·고객사·태그. 제목이 버튼이라 키보드로 팝업을 열 수 있음.
- 전체 프로젝트: 한 줄씩 목록(제목 / 번호·기간·참여 기간·PM·PL·정부과제·태그·소속·고객사·팀 규모 / 연도). 위에 개수(`aria-live`), 검색 칸(`<label>` 있음, 제목·고객사·소속·협력사·태그에서 찾음), 필터 버튼(PM·PL·정부과제·방법·분야, `<button aria-pressed>`). 검색과 필터는 함께 적용(둘 다 맞는 것). 처음에는 최근 8개, "Show all"로 전부. 필터나 검색을 쓰면 맞는 것 전부.
- 논문: 왼쪽에 연도, 한 줄씩([번호] 제목 / 저자 / 학회지·1저자 / 종류·"View Paper ↗"). 위에 개수와 종류 필터(지금 필터 그대로). 페이지 넘기기 없음.
- 수상: 한 줄씩(이름 / 기관·설명·비고 / 날짜). 특허: 지금처럼 따로 섹션(`#patents`), 한 줄에 제목, 아래에 상태·출원번호·출원일·출원인·발명자·출원국. 활동: 한 줄씩(역할 / 기관 / 기간·장소), 아이콘은 없앰.
- 연락처: 큰 글자 링크 줄(항목 이름, 오른쪽 →), 그 아래 작은 글자로 실제 주소. 지금 나오는 항목(이메일·LinkedIn·Scholar·Google Site·위치) 그대로. 긴 주소는 줄바꿈.
- 팝업은 브라우저 기본 `<dialog>`로 바꿈. 바깥 클릭으로 닫기·스크롤 잠금은 직접 처리, 닫으면 연 버튼으로 포커스가 돌아옴.
- 새 문구("27 projects", "Show all", 검색 칸 안내 등)는 영어·한국어 둘 다 i18n 키로.
- 없애는 것: 페이지 넘기기(`createCarousel`)와 카드 높이 맞춤(subgrid). 그래서 [ux-03](#ux-03)(페이지 번호 이동)은 필요 없어지고, [ux-02](#ux-02)의 검색은 프로젝트 검색으로 일부 채움(논문 검색은 ux-02에 남김).
- 시안: 로컬 비교 페이지 `rec.html`(예시 데이터).
- 참조: index.html, assets/css/style.css, assets/js/main.js, docs/ui/design-system.md, docs/ui/components.md, docs/ui/sections.md, docs/qa/user-scenarios.md
- QA: 영어·한국어, 390px·700px·1440px, 밝은·어두운 테마에서 가로 스크롤 없음, 콘솔 오류 없음. 지금 화면에 있는 항목이 모두 보임. 프로젝트 검색·필터 결과 개수가 맞음. 경력 탭을 바꾸면 상세가 바뀜(키보드 화살표 포함). 팝업은 키보드로 열고 Esc·바깥 클릭으로 닫히며 포커스가 돌아옴. 사용자 시나리오(UC-2~UC-14)는 새 화면에 맞게 고쳐 전부 통과.
